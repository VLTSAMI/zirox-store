# 🛍️ Zirox Store Algeria — متجر زيروكس الإلكتروني الفاخر

منصة تجارة إلكترونية جزائرية متكاملة ولوحة تحكم إدارية احترافية مبنية بأحدث معايير الويب (Modern Vanilla JS & CSS Architecture).

![Zirox Store Preview](assets/zirox-hero-logo.png)

---

## ✨ المميزات الرئيسية (Key Features)

### 🏬 واجهة المتجر العام (Storefront)
- **تصميم فخم وعصري (Luxury Aesthetics):** وضع ليلي فائق الأناقة (Dark Mode) ووضع نهاري متناسق مع مؤثرات بصرية وتفاعلية دقيقة.
- **تعدد اللغات الكامل (i18n):** دعم كامل للغات العربية 🇩🇿، الفرنسية 🇫🇷، والإنجليزية 🇬🇧 مع تبديل ديناميكي لاتجاه الصفحة (RTL / LTR).
- **نظام شحن لكافة الـ 69 ولاية:** احتساب تلقائي ودقيق لأسعار وأوقات التوصيل (شحن مجاني، التوصيل للمنزل أو المكتب عبر ياليدين إكسبريس).
- **سلة مشتريات تفاعلية و Checkout سلس:** شريط تقدم للشحن المجاني، نموذج طلب محسّن بنقرة واحدة، والدفع عند الاستلام (Cash on Delivery).
- **عرض المنتجات وتفاصيلها:** معرض صور متكامل، مواصفات تقنية متعددة اللغات، ومراجعات موثقة.

### 🛡️ لوحة التحكم الإدارية (Admin Dashboard - SPA)
- **تسجيل دخول آمن ومحمي:** حماية ضد محاولات التخمين (Rate Limiting & Lockout).
- **لوحة إحصائيات عامة (Overview):** 8 بطاقات رقمية شاملة لحساب الإيرادات، المبيعات، ومخزون المنتجات.
- **إدارة المنتجات الكاملة (Products CRUD):** إضافة، تعديل، استنساخ، وحذف فردي وجماعي مع محرر مواصفات ثلاثي اللغات (AR/FR/EN).
- **إدارة الطلبيات (Orders Management):** فلاتر متقدمة بحسب الحالة، تغيير الحالات، وطباعة فواتير رسمية قابلة للطباعة بنقرة زر.
- **إدارة الشحن والمناطق:** تحكم كامل في تصنيف الولايات الـ 69، أسعار الشحن، وحد الشحن المجاني.
- **النسخ الاحتياطي والاستعادة:** تصدير واستيراد البيانات بتنسيق JSON و CSV مع دعم كامل لترميز UTF-8 BOM.

---

## 🏛️ المعمارية البرمجية (Architecture)

- **نمط المستودع والمحوّل (Repository & Adapter Pattern):** فصل كامل بين طبقة منطق الأعمال والبيانات؛ جاهز للتبديل الفوري بين `LocalStorage` وقواعد البيانات الحقيقية (`REST API` / `Supabase` / `PostgreSQL`) بسطر واحد.
- **دعم كامل لـ Async/Await:** جميع عمليات استرجاع البيانات والـ CRUD غير متزامنة ومستعدة للاتصال المباشر بالخوادم وقواعد البيانات.
- **Bundling & Production Ready:** تم تجميع الكود مسبقاً عبر `esbuild` ليعمل بسلاسة حتى على بروتوكول `file://` وخوادم الاستضافة الثابتة مثل GitHub Pages.

## 🚀 كيفية التشغيل محلياً (Quick Start)

### الطريقة 1: عبر ملف التشغيل السريع (Windows)
اضغط نقراً مزدوجاً على ملف:
```bash
تشغيل-المتجر.bat
```
سيقوم تلقائياً بتشغيل الخادم المحلي وفتح لوحة الإدارة والمتجر في متصفحك.

### الطريقة 2: عبر Python أو Node.js
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve .
```
ثم افتح:
- المتجر: `http://localhost:8000/index.html`
- لوحة الإدارة: `http://localhost:8000/admin.html`

> 🔑 **بيانات الدخول الافتراضية للوحة التحكم:**
> - كلمة المرور: `zirox-admin-2026`
